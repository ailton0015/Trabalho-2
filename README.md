# Lion App - Documentação de Entradas Financeiras e Mapeamento Bancário

Repositório criado para a entrega do desafio prático de documentação técnica e controle de versão no GitHub.

## 📌 Sobre o Projeto
Este repositório contém a organização técnica e o mapeamento de notas bancárias/holerites do ecossistema **Lion App**, além de uma tabela complementar de apoio contendo os códigos COMPE e instituições financeiras do Sistema Financeiro Nacional.

## 📁 Arquivos do Repositório
- `README.md`: Documentação geral do projeto.
- `Lion_App_Notas_Financeiras.xlsx`: Planilha com os registros de entradas, categorias, valores e lista de códigos bancários.

## 🎯 Objetivos Concluídos
- Aplicar conceitos de documentação técnica clara e estruturada.
- Organizar e versionar arquivos de suporte financeiro no GitHub.
- Utilizar a sintaxe Markdown para apresentação do projeto.
